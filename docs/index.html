CodeMesh · HTML 工件 showcase

CodeMesh 是国内多模型 Code Agent（学习 / 面试项目）。本页陈列项目里所有 "给人看"的 HTML 工件——dashboard、edit diff、planner timeline、架构图。 都是单文件自包含、零外链 / 零 JS 框架，可以直接发简历或贴公众号文章。

"Diff、调用图、并排比较都是空间信息，markdown 是线性的——会丢一个维度。 Agent 应该输出自包含的 HTML 文件而不是大段 markdown。" — thariqs · The Unreasonable Effectiveness of HTML
report

Stats dashboard

本地调用统计的可视化版：KPI 卡片、模型成本横条、调用占比 pie、按天 sparkline、详细表格。

codemesh stats --html
默认写到 .codemesh/reports/stats-<ts>.html，--output 自定义路径。 数据源跟 codemesh stats 同一份 ~/.codemesh/calls.jsonl。
tool

Edit diff

每次模型调 edit_file 改文件后，顺手把 unified diff 渲染成单页 HTML。绿/红块、行号、上下文。

export CODEMESH_HTML_DIFF=1
启用后每次 edit 自动写到 .codemesh/diffs/。默认关，避免无意义垃圾。
plan

Planner timeline

complex 任务走 planner-executor 时，渲染每步的执行情况：拓扑、模型分配、状态、耗时占比、成本。

export CODEMESH_HTML_PLAN=1
启用后跑 complex 任务自动写到 .codemesh/plans/。simple 任务不会触发。

设计原则（不踩 thesis 的坑）

  • HTML 工件给人看，不给 agent 吃：tool returns 仍然是字符串。把 read_file / grep_text 改 HTML 会污染 token 经济，模型也消化不了。
  • 单文件自包含 / 零外链：CSS 全 inline、SVG 手画、零 JS 框架。可以直接发简历 / 贴公众号 / 离线归档。
  • 零新 PyPI 依赖：所有渲染走 Python 标准库（difflib、字符串模板）。requirements.txt 没新增一行。
  • opt-in 默认安静：env CODEMESH_HTML_DIFF=1 / CODEMESH_HTML_PLAN=1 控制；不开就完全跟以前一样。
  • 滚动保留：.codemesh/diffs/、.codemesh/plans/、.codemesh/reports/ 都按 mtime 自动滚动 20 个，不会无限堆积。
  • 不动叙事产物：README / DEVLOG / LEARNING_PATH 一行不改（CLAUDE.md 红线）。HTML 工件全部走 docs/ 或运行时目录。
