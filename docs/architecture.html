反馈层 · feedback/ observer · cost · log · compact · journal · dreamer · render

RAG · rag/（横向插入编排层） 代码库索引 + 检索 + 重排

RAG 不是 4 层之一，而是"任务进入前的可选前置"：--rag 时 retrieve 拿 top-k 代码片段 → 拼到 system prompt → 再走正常 4 层。 代码搜索其实**不靠这层**——Claude Code / OpenHarness 的事实标准是 grep + AST。 本层保留作"非代码场景的 RAG"（文档库 / 知识库）。
